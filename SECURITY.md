# Security Policy

## Supported versions

DefaultAppGuard is currently an alpha. Security fixes are applied only to the
latest published prerelease.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for issues involving
origin checks, loopback API access, installer path validation, scheduled-task
registration, or unintended registry changes.

Do not post exploit details, tokens, personal registry exports, or local runtime
files in a public issue. A public bug report is appropriate after sensitive
details have been removed.
